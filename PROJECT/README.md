# Musify – Hindi music app
Run (needs only Node.js):

    cd backend
    node server.js
    open http://localhost:3000

- 130+ Hindi songs. Cover art + 30-second previews come from Apple's free iTunes Search API (internet needed).
- Full-length audio: put .mp3 files in backend/songs/ named "Artist - Title.mp3".
- Keys: Space, ←/→, L like, S shuffle, R repeat, Q queue, M mute, / search.
